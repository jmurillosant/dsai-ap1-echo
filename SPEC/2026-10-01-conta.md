# Conta (2026-10-01)

## O que e por que

O sistema de contas e a porta de entrada do Echo. Permite que pessoas se registrem, entrem e saiam, garantindo que apenas usuarios autenticados possam interagir com as funcionalidades restritas.

## Criterios de aceitacao

Cadastro:
- O sistema deve ter uma pagina com formulario contendo nome de usuario, email, senha e confirmacao de senha.
- O sistema deve criar o usuario no banco quando todos os dados forem validos.
- Apos cadastro bem sucedido, o sistema redireciona para a pagina de login.
- O sistema deve exibir erro se o nome de usuario ja existir.
- O sistema deve exibir erro se o email ja existir.
- O sistema deve exibir erro se as senhas nao coincidirem.
- Senhas nunca sao salvas em texto puro.

Login e Logout:
- O sistema deve ter uma pagina de login com campos de nome de usuario e senha.
- O sistema autentica e cria sessao quando as credenciais estao corretas.
- Apos login bem sucedido, o sistema redireciona para uma pagina temporaria de boas vindas.
- O sistema exibe "Credenciais invalidas" quando usuario ou senha estao errados, permanecendo na pagina.
- O sistema deve ter um link ou botao para logout.
- Apos logout, a sessao e destruida e o usuario volta para a pagina de login.

Testes:
- O app core deve ter testes que validem cadastro com dados corretos.
- Os testes devem validar rejeicao de cadastro duplicado.
- Os testes devem validar login correto e rejeicao de credenciais erradas.
- Os testes devem validar logout e destruicao da sessao.

## Fora do escopo

- Recuperacao de senha por email.
- Login social (Google, Facebook, etc).
- Verificacao de email.
- Edicao de perfil.
- Estilizacao visual complexa.
